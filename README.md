# Spartito da Audio

App web che trasforma una melodia in spartito per lo strumento scelto.

- Registra dal microfono (canta, fischia o suona) oppure carica un file audio
- Riconoscimento delle note, stima di tempo e tonalità
- 15 strumenti con trasposizione, chiave ed estensione automatiche
- Editor ABC, riproduzione, archivio locale
- Esportazione in MusicXML, MIDI, SVG e ABC

Apri `index.html` da un indirizzo https (es. GitHub Pages) per usare il microfono.
Gli spartiti ottenuti da registrazioni di brani protetti sono per uso personale.
